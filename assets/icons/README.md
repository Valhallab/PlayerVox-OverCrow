# Overlay icon assets

- `tabler-icons-overcrow.ttf` is a glyph subset generated from
  `@tabler/icons-webfont` 3.45.0. Tabler Icons is MIT-licensed; its notice is
  included in the repository-level `NOTICE` file.
- `discord-symbol-blurple.png` is the official Discord symbol downloaded from
  the [Discord brand page](https://discord.com/branding). It is proportionally
  downscaled without modifying the source asset. OverCrow derives a monochrome
  runtime mask so every use follows the shared icon palette.
- `twitch-glitch-purple.png` is the official Twitch Glitch downloaded from the
  [Twitch press center](https://www.twitch.tv/p/press-center/). It is
  proportionally downscaled without modifying the source asset. OverCrow
  derives a monochrome runtime mask while preserving its knockout.

The brand marks identify optional service integrations only. They are not
licensed as part of OverCrow and must not be reused as PlayerVox branding.
